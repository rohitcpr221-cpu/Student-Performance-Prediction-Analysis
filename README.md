# Student Performance Prediction & Analysis

## Project Overview
A machine learning project that analyzes student-related data and predicts academic performance using regression and classification algorithms.

## Business Problem
Educational institutions need to understand student performance patterns and identify students who may be at risk of failing.

This project explores student characteristics and builds machine learning models to predict final grades and pass/fail outcomes.

## Objectives
- Explore student academic and demographic data.
- Perform data preprocessing.
- Encode categorical variables.
- Predict final student grades.
- Classify students into pass/fail categories.
- Compare different machine learning algorithms.
- Evaluate model performance.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Machine Learning Models

### 1. Linear Regression
Predict student final grades using available student attributes.

### 2. Logistic Regression
Classify students into pass/fail categories.

### 3. Decision Tree Classifier
Predict student pass/fail outcomes using decision tree classification.
